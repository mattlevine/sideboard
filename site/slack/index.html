Slack

Tell a teammate a PR is ready

Agents post as @Sideboard and read the reply. The phone app is still how you reach this Mac.

Connect a team

Settings → Collaboration → Add via browser installs the Sideboard Slack app into one workspace. Click it again to add another team. You can also paste an xoxb- or xoxp- token. Each connected team stays on this Mac until you disconnect it.

This Mac

Name this Mac under Settings → Remote. The phone and Slack both use that name. The relay address there is for the phone. Slack sign-in and Listen stay on Sideboard’s Slack relay. A reply can come back as Work: …. Start a DM with work: or personal: when more than one Mac is listening.

Message text is not used to train models. Repos and secrets stay on the Mac. Product questions go to the community Slack (sideboard-ai.slack.com), which is not the same as installing the app into your team. Email support@sideboard.build.
