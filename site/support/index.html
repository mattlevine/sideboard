Support

Get help

No extra account. Email is enough — we aim to reply within two business days. For a faster back-and-forth, join the community Slack.

Email

support@sideboard.cloud

Include what you were doing (install, Slack DM, Listen, land), the Sideboard version if you know it, and the Slack workspace name. Do not send tokens, .env files, or vault dumps.

Community Slack

sideboard-ai.slack.com

A public Sideboard workspace for questions and hangout. It is not the same as installing the Sideboard Slack app into your own team so you can DM this Mac — that setup is on Slack app setup.

  1. Open sideboard-ai.slack.com.
  2. Enter your email and continue.
  3. Enter the confirmation code Slack emails you.
  4. If you are not a member yet, follow Slack’s prompt to create an account for this workspace (or request an invite).

Already in Slack? Workspace switcher → Add a workspace → Sign in to another workspace → sideboard-ai. If the page asks for an invite you do not have, email support and we will send one.

Security reports go to the same inbox. Do not post them publicly (including in Slack). See Security.
