Support

Get help

No extra account. Email is enough. We aim to reply within two business days.

Email

support@sideboard.cloud

Include what you were doing (install, Slack DM, Listen, land), the Sideboard version if you know it, and the Slack workspace name. Do not send tokens, .env files, or vault dumps.

GitHub issues are optional and require a GitHub account — use email if you do not want that. Security reports: same inbox, or a private GitHub Security Advisory; do not file a public issue.
